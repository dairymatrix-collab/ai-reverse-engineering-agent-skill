# Security Policy

## Scope

This repository contains agent instructions and a small offline manifest utility. It does not provide an exploit framework or collect telemetry.

## Reporting a vulnerability

Do not publish secrets, credentials, private captures, or exploit details in a public issue. Report security problems privately through the repository's GitHub security contact once the repository is published, or open an issue that contains only a high-level description and asks for a private channel.

## Safety boundary

The skill is intended for authorized security research, software auditing, interoperability, preservation, debugging, education, and clean-room reconstruction. It must not be used to bypass access controls, steal credentials, deploy malware, evade licensing, or tamper with online services.
